# 07 Crosswalks

Goal: map matches, teams and players across providers.

- team_crosswalk first (small, partly manual), then match_crosswalk (date + teams),
  then player_crosswalk (name + birth date + team + shirt number; check Reep register).
- Every mapping keeps how it was made (`method`) and how sure we are (`confidence`).
- Write a report of unmatched rows per source; aim for zero unmatched on overlapping data.
- Done when: all WC 2022 and WC 2018 matches mapped across providers, unmatched list reviewed.
